Installation Instructions

  1. Gmail: Settings → See all settings → General → Signature → Create new. Click the "<>" HTML toggle in the rich text editor, paste the HTML code below, and save.
  2. Outlook 365: File → Options → Mail → Signatures → New. Use the HTML editor or paste via "Edit in browser" mode. Images must be linked, not embedded.
  3. Apple Mail: Preferences → Signatures → select your account → drag and drop from the preview above into the signature field.
  4. Replace all fields shown in [brackets] with your actual name, title, email, and phone number before saving.
  5. Contact it@restoredocai.com for the HTML source file or assistance with non-standard email clients.
